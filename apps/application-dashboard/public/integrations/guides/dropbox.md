# Dropbox Integration Guide

Connect Dropbox to access files, sync documents, and streamline your file management workflow within Zamp.

## Prerequisites

- A Dropbox account (Basic, Plus, or Business)
- Files you want to sync

## Setup Instructions

### Step 1: Connect Dropbox

1. Go to **Integrations** → **Dropbox**
2. Click **Connect**
3. Sign in to your Dropbox account
4. Grant Zamp access to your files

### Step 2: Choose Access Level

Select the appropriate access:

- **Full Dropbox**: Access all files and folders
- **App Folder**: Access only a dedicated Zamp folder

### Step 3: Select Folders

1. Browse your Dropbox structure
2. Select folders to sync
3. Set sync preferences (one-way or two-way)

## Features

### File Import

- Import CSV, Excel, and PDF files
- Automatic data extraction
- Scheduled imports

### File Export

- Export reports to Dropbox
- Automatic backups
- Version control

### Document Linking

- Attach Dropbox files to records
- Preview documents inline
- Share links securely

## Supported File Types

| Type         | Extensions  | Auto-Parse |
| ------------ | ----------- | ---------- |
| Spreadsheets | .xlsx, .csv | ✅ Yes     |
| Documents    | .pdf, .docx | ✅ Yes     |
| Images       | .png, .jpg  | ❌ No      |
| Archives     | .zip        | ❌ No      |

## Best Practices

1. **Organize folders** - Use clear naming conventions
2. **Set up auto-sync** - Keep data up-to-date automatically
3. **Use selective sync** - Only sync what you need
4. **Enable notifications** - Get alerted on file changes

## Storage Considerations

> ⚠️ Large file syncs may take time. Consider syncing during off-peak hours for better performance.
