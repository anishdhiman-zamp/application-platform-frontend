# Miro Integration Guide

Bring your Zamp data into Miro for visual collaboration, brainstorming, and interactive presentations.

## Prerequisites

- A Miro account with appropriate permissions
- At least one Miro board

## Setup Instructions

### Step 1: Connect Miro

1. In Zamp, go to **Integrations** → **Miro**
2. Click **Connect**
3. You'll be redirected to Miro's authorization page
4. Select the team you want to connect
5. Click **Allow**

### Step 2: Select Boards

1. Choose which boards to sync with Zamp
2. Set permissions (view, edit, or admin)
3. Configure auto-sync preferences

### Step 3: Embed Data

1. Open a Miro board
2. Use the Zamp widget to embed live data
3. Customize visualization options

## Use Cases

### Visual Data Mapping

Create visual representations of your data:

- Flowcharts from process data
- Mind maps from hierarchical data
- Kanban boards from task data

### Collaborative Planning

- Sprint planning with live metrics
- Roadmap visualization
- Stakeholder presentations

### Workshops & Retrospectives

- Import data for analysis
- Annotate and discuss
- Export insights back to Zamp

## Features

- **Live Data Widgets**: Embed real-time data from Zamp
- **Two-way Sync**: Updates reflect in both platforms
- **Templates**: Pre-built templates for common use cases
- **Export**: Send Miro content back to Zamp

## Tips

> 💡 **Pro Tip**: Use Miro's frames to organize different data views and create presentation-ready boards.
