# Linear Integration Guide

Connect your Linear workspace with Zamp to automatically sync issues, track project progress, and streamline your workflow.

## Prerequisites

- A Linear account with admin access
- API key from Linear settings

## Setup Instructions

### Step 1: Generate API Key

1. Go to **Linear Settings** → **API** → **Personal API Keys**
2. Click **Create Key**
3. Give it a descriptive name (e.g., "Zamp Integration")
4. Copy the generated key

### Step 2: Connect to Zamp

1. Navigate to **Integrations** in Zamp
2. Find **Linear** and click **Connect**
3. Paste your API key
4. Select the workspaces you want to sync
5. Click **Authorize**

### Step 3: Configure Sync Settings

- Choose which issue types to sync
- Set up automatic status updates
- Configure notification preferences

## Features

| Feature        | Description                                       |
| -------------- | ------------------------------------------------- |
| Issue Sync     | Automatically sync issues between Linear and Zamp |
| Status Updates | Real-time status synchronization                  |
| Comments       | Sync comments and discussions                     |
| Attachments    | Share files across platforms                      |

## Troubleshooting

### Connection Issues

If you're having trouble connecting:

1. Verify your API key is correct
2. Ensure you have admin permissions
3. Check if the Linear API is accessible

### Sync Delays

Sync typically happens within 1-2 minutes. If delays persist, try:

- Refreshing the connection
- Checking your network connection
- Contacting support
